# Approved in-app brand assets

`estacoda-eye.svg` retains the supplied paths, using the approved cropped viewBox `20 130 475 255`.
`estacoda-wordmark.svg` preserves the official supplied 1076 × 282 raster letterforms inside the approved SVG alpha mask. It is a raster-backed SVG derivative, not a newly drawn or original vector wordmark. The luminance-to-alpha filter removes the reference backdrop; theme color supplies the ink. No approximate typeface is substituted.

Both are extracted from frozen design version 1 by `scripts/import-approved-design.mjs`. Visual acceptance checks light/dark backgrounds and 1×/2× rendering. The macOS application icon is separately documented under `assets/icons`.
