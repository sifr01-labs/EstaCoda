# PR5–PR7 native acceptance evidence

macOS arm64 / Electron 44.3.0. Run `pnpm run desktop:package` then `pnpm run desktop:native` from the repository root in a graphical session. Tests explicitly override Electron home and userData before loading production Main; setting HOME alone is insufficient on macOS. All displayed Work, pending approvals and credentials are synthetic temporary data. One bounded model request is sent to a test-owned loopback server, and reviewed setup writes only the temporary test profile. No paid provider requests or real user-profile writes occur. PR7 dispatches to a deterministic test runtime behind the real shared owner, resolves a synthetic approval once, and exercises canonical Task/model operator services.

- `results.json` and `canonical-work.png`: actual Main/preload/standalone Node bridge reads current-schema persisted Work and pending attention. Profile switches, reload, bridge termination, supervisor restart, incompatible host and quit/relaunch preserve canonical ownership.
- `models-configured.png`: production Models setup, one streamed/tool-compatible local verification and reviewed no-auth primary Apply. Latest-Apply inspection succeeds after a full application restart.
- `native-200-percent.png`: settled 200% zoom, reachable composer and no horizontal overflow. Electron's native capture API avoids CDP's clipped Retina zoom screenshot. Resize checks also exercise 1280, 736 and 360 px.
- `incompatible-host.png`: explicit recovery state for an existing incompatible owner; Desktop does not replace it.
- `package.json`: fixture exclusion, strict release CSP, hardened fuses including file-protocol privilege denial, exact supplied-icon derivative hash, strict local signature verification, and unchanged packaged launch from a path containing spaces and Arabic.

Boundary checks reject a foreign genuine renderer with the same preload/document, forged profiles, credential calls from an unrelated renderer, arbitrary local-file fetch, external navigation, popups and notification permission. Synthetic credential submission uses the production Models dialog and real private descriptor 3; the credential window closes after transfer, and cancelling setup saves no credential/config. The ordinary renderer has semantic setup methods but cannot submit or read a raw key. Unit tests additionally check stale generations, protocol bounds and correlation, credential pipe failures, presentation validation and bounded reconnect backoff.

These results cover PR5 bootstrap/inspection, PR6 provider setup/verification/recovery and PR7 Work controls. The native picker stages actual UTF-8 contents; Main/preload/bridge submit them once, then canonical search, pins, approve-once, model override and bounded Task creation/pause are checked. App restart preserves pending-operation inspection, pins and paused Tasks; a supervisor restart preserves settled receipt inspection without resending the prompt. Real-account Codex login, paid-model execution and production soak monitoring remain outside these deterministic journeys. Native evidence supplements the [visual/interaction gate](../visual-evidence/README.md); it does not replace that gate. Operating-system title-bar controls are native on the tested macOS platform and therefore absent from renderer-only captures. Windows/Linux native release validation remains outstanding.
