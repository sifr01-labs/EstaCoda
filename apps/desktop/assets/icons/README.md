# EstaCoda desktop icon

- `estacoda-icon.png`: 1024 × 1024 transparent PNG for app packaging.
- `estacoda.icns`: macOS icon with 16–1024 px representations, including Retina sizes.
- `estacoda-icon-source.png`: 640 × 640 transparent source canvas retaining original interior pixels.

Extracted directly from the large upper-left icon in the user-provided branding poster. No AI-generated reconstruction is used. The surrounding poster and external shadow were removed using an antialiased outline mask; original color pixels inside the opaque mask are unchanged. The tile occupies roughly 540 × 515 source pixels. Larger exports use Lanczos resampling, not newly generated detail. Original proportions are preserved.

Checked against light and dark backgrounds; verified source interior pixel equality, PNG transparency and dimensions, and every embedded ICNS representation. Packaging integration is deferred until the desktop app packager exists.
